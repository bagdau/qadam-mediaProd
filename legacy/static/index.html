Пошаговая настройка TikTok API

Не настроено
1

Создайте TikTok Developer App

На developers.tiktok.com откройте Manage apps → Connect an app. Добавьте Login Kit и Content Posting API.

2

Запросите разрешения

Добавьте scopes: user.info.basic и video.publish. Для публичного размещения отправьте приложение на аудит TikTok.

3

Добавьте Redirect URI

Скопируйте адрес ниже в настройки Login Kit. Адрес на сервере должен работать по HTTPS.

—
4

Заполните серверный .env

Укажите TIKTOK_CLIENT_KEY, TIKTOK_CLIENT_SECRET и такой же TIKTOK_REDIRECT_URI. Секрет нельзя вставлять в браузер.

ШАГ 5

Подключите личный TikTok-аккаунт

TikTok откроет свою страницу и попросит разрешить Qadam Media публикацию видео. Пароль аккаунта Qadam Media не получает.
